# Publishing `@ringdom/legiox-mcp` to npm

Maintainer checklist — run once to register, then per release.

## 0. Prerequisites (one-time)

1. **npm account**: https://www.npmjs.com/signup — any handle; use `ray@ringdom.org` for consistency. Verify the email (npm requires verified email to publish).
2. **Create the `ringdom` org/scope**: npmjs.com → your avatar → **Organizations → Create Organization** → name: `ringdom` (free tier; public packages are free). You need to be the owner of the `@ringdom` scope to publish `@ringdom/*`.
3. **Login locally**:
   ```bash
   npm login
   ```
   (Browser or OTP flow; token stored in `~/.npmrc`.)

## 1. Prepare the package (already scaffolded)

```bash
cd packages/legiox-mcp
npm install            # verify deps resolve
node legiox-mcp/legiox-mcp-server.js --test   # health check
npm pack --dry-run     # preview contents (should list: legiox-mcp/, legiox-truth-lens/, cohorts/, AI-AGENT-INDEX.json, LEGIOX-COHORTS.json, scripts/, README.md)
```

> The bundle content (`legiox-mcp/`, `legiox-truth-lens/`, `cohorts/`, indexes) is regenerated by `pack-legiox-plugins.mjs` — refresh this dir before each release from the latest `legiox-free/mcp/AI-LEGIOX/` (excluding `node_modules`).

## 2. Publish (first time)

```bash
npm publish --access public
```

`publishConfig.access: "public"` is already set in `package.json`, so subsequent publishes stay public.

## 3. Verify

```bash
npm view @ringdom/legiox-mcp version
npx -y @ringdom/legiox-mcp --test     # from a clean temp dir
```

## 4. Wire the plugins to npx (the marketplace-safe pattern)

Replace the plugin-relative `mcp.json` server with the npx invocation — this removes the Cursor plugin-relative-path risk entirely:

```json
{
  "mcpServers": {
    "legiox-mcp": {
      "command": "npx",
      "args": ["-y", "@ringdom/legiox-mcp"],
      "env": {
        "LEGIOX_FILE_INFO_BACKEND": "filesystem"
      }
    }
  }
}
```

## 5. Per-release

```bash
cd packages/legiox-mcp
npm version patch     # bumps to 1.0.3, creates git tag
npm publish
```

Keep npm version aligned with the GitHub release tag (v1.0.3).
