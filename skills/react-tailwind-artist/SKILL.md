# React Tailwind Artist

## Summary

Artisan layer: @property definitions for gradient animations, 3D transforms (rotate-x/y/z, perspective, backface-hidden), @starting-style mount animations replacing framer-motion for simple cases, OKLCH color system for P3 wide-gamut.

## When to use

- complex CSS animations
- 3D transform effects
- gradient animations
- OKLCH color palettes
- performance-focused animation

## Instructions

1. @starting-style variant for JS-free entry animations
2. 3D: perspective-*, rotate-x/y/z-*, backface-hidden
3. @property for smooth gradient transitions
4. Motion division: Tailwind for hover/focus, framer-motion for orchestration
